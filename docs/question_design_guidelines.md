# 質問設計ガイドライン

## 基本方針

距離感診断の質問は、「二人の関係における距離感」に特化した内容とし、回答者の本音を引き出すことを目的とします。

## 質問の種類

### 距離感の観点

1. **物理的距離感**
   - 会う頻度、連絡頻度
   - 一緒に過ごす時間の長さ

2. **心理的距離感**
   - お互いのことをどの程度知っているか
   - 本音を話せる度合い
   - 依存度、自立度

3. **社会的距離感**
   - SNSでの関係性の見せ方
   - 他の人への紹介度合い
   - 公にしている度合い

4. **コミュニケーション距離感**
   - 連絡の頻度とタイミング
   - 会話の深さ
   - 話題の範囲

## closer_side の決定基準

### `closer_side: 'left'`（そう思う側が距離感が近い）を選ぶべきケース

「そう思う」と答えた人が、距離感が近い関係を望んでいる、または既に近い関係であることを示す質問。

**例:**
- 「日常的に連絡を取り合いたいと思いますか？」
  - 「そう思う」→ 連絡頻度が高い = 距離感が近い
  - 「そう思わない」→ 連絡頻度が低い = 距離感が遠い

### `closer_side: 'right'`（そう思わない側が距離感が近い）を選ぶべきケース

「そう思わない」と答えた人が、距離感が近い関係を示す質問。

**例:**
- 「一人の時間が必要だと思いますか？」
  - 「そう思う」→ 一人の時間を必要とする = 距離感が遠い
  - 「そう思わない」→ 一人の時間が不要 = 距離感が近い

## 質問設計の原則

### 1. 明確性
- 質問は1つの概念について尋ねる
- 曖昧な表現を避ける
- 「〜そう思いますか？」という形式で統一

### 2. 回答のしやすさ
- 日常的な体験に基づく質問
- 具体的な場面をイメージしやすい質問
- 過度に抽象的な質問を避ける

### 3. バランス
- `closer_side: 'left'`と`closer_side: 'right'`の質問を適切に配置
- 推奨: 15問ずつ、またはバランス良く配置
- 偏りがないように注意

### 4. 距離感への焦点
- すべての質問が「距離感」に関連していること
- 関係性の深さ、近さを測る質問であること

## 質問の分類

### カテゴリ1: 連絡・コミュニケーション（6-8問）
- 連絡頻度
- 返信速度
- 会話の深さ
- 連絡方法の多様性

### カテゴリ2: 時間の共有（5-7問）
- 会う頻度
- 一緒に過ごす時間
- 一人の時間の必要性
- スケジュールの共有度

### カテゴリ3: 親密度・信頼関係（6-8問）
- 本音を話せる度合い
- 相談しやすさ
- 秘密の共有度
- 頼りにされる度合い

### カテゴリ4: 社会的関係性（5-7問）
- SNSでの関係性
- 他の人への紹介
- 公にしている度合い
- グループ内での関係性

### カテゴリ5: 感情・依存度（4-6問）
- やきもちを焼く度合い
- 依存度
- 優先順位
- 独占欲

## 質問作成時のチェックリスト

- [ ] 質問が距離感に関連しているか
- [ ] `closer_side`が適切に設定されているか
- [ ] 質問が明確で理解しやすいか
- [ ] 回答者がイメージしやすい具体性があるか
- [ ] `closer_side`のバランスが取れているか
- [ ] 重複する質問がないか
- [ ] すべての質問が「〜そう思いますか？」形式か

## 良い質問の例

### ✅ 良い例1
**質問**: 「日常的に連絡を取り合い、頻繁にやりとりしたいと思いますか？」  
**closer_side**: `'left'`  
**理由**: 「そう思う」と答えた人は連絡頻度を高くしたい = 距離感が近い

### ✅ 良い例2
**質問**: 「一人の時間も必要で、適度な距離感を保ちたいと思いますか？」  
**closer_side**: `'right'`  
**理由**: 「そう思わない」と答えた人は一人の時間が不要 = 距離感が近い

## 避けるべき質問

### ❌ 悪い例1: 距離感に関係ない
**質問**: 「趣味が同じだと良いと思いますか？」  
**理由**: 趣味の一致は距離感とは直接関係ない

### ❌ 悪い例2: 曖昧
**質問**: 「関係が良いと思いますか？」  
**理由**: 「良い関係」の定義が不明確

### ❌ 悪い例3: 二重の質問
**質問**: 「連絡を取り合い、よく会って、SNSでも交流したいと思いますか？」  
**理由**: 複数の概念が混在している

## 質問の順序

1. 簡単な質問から始める（連絡頻度など）
2. より個人的な質問へと進む（本音、秘密など）
3. 最後に感情的な質問（依存度、独占欲など）

この順序により、回答者が徐々に深く考えられるようになります。
