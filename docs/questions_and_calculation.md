## スコア計算の全体フロー

### ステップ1: 個人ポイント計算

各質問について、回答値（0-5）を`closer_side`に基づいてポイント（+3〜-3点）に変換し、合計する。

```javascript
// Aさんのポイント計算例
scoreA = 0;
for (question of allQuestions) {
  answer = answersA[question.id];  // 0-5
  if (question.closer_side === 'left') {
    point = 3 - answer;  // 0→+3, 1→+2, 2→+1, 3→-1, 4→-2, 5→-3
  } else {
    point = answer - 3;  // 0→-3, 1→-2, 2→-1, 3→+1, 4→+2, 5→+3
  }
  scoreA += point;
}
```

**範囲**: -90 〜 +90点（30問 × ±3点）

### ステップ2: 距離感スコア計算

```javascript
totalPoints = scoreA + scoreB;  // 範囲: -180 〜 +180
distanceScorePercent = ((totalPoints + 180) / 360) * 100;  // 範囲: 0 〜 100%
// -180点 → 0%、0点 → 50%、+180点 → 100%
```

### ステップ3: 相性スコア計算

```javascript
diff = Math.abs(scoreA - scoreB);  // 範囲: 0 〜 180
compatibilityScorePercent = 100 - (diff / 180) * 100;  // 範囲: 0 〜 100%
```

## 計算例

### 例1: 全て「最もそう思う」で回答（closer_side='left'の質問）

- Aさん: 全18問のleft質問で回答0 → +54点、全12問のright質問で回答0 → -36点 → 合計 +18点
- Bさん: 全18問のleft質問で回答0 → +54点、全12問のright質問で回答0 → -36点 → 合計 +18点

```
totalPoints = 18 + 18 = 36
distanceScorePercent = ((36 + 180) / 360) * 100 = 60%
diff = |18 - 18| = 0
compatibilityScorePercent = 100 - (0 / 180) * 100 = 100%
```

結果: 距離感60%（繰り上げで60%）、相性100%

### 例2: バランス良く回答

- Aさん: 15問で「ややそう思う」（+1）、15問で「ややそう思わない」（-1）→ 合計0点
- Bさん: 15問で「ややそう思う」（+1）、15問で「ややそう思わない」（-1）→ 合計0点

```
totalPoints = 0 + 0 = 0
distanceScorePercent = ((0 + 180) / 360) * 100 = 50%
diff = |0 - 0| = 0
compatibilityScorePercent = 100 - (0 / 180) * 100 = 100%
```

結果: 距離感50%（繰り上げで50%）、相性100%

### 例3: 完全に正反対の回答

- Aさん: 全left質問で「最もそう思う」（+54）、全right質問で「最もそう思う」（-36）→ +18点
- Bさん: 全left質問で「全くそう思わない」（-54）、全right質問で「全くそう思わない」（+36）→ -18点

```
totalPoints = 18 + (-18) = 0
distanceScorePercent = ((0 + 180) / 360) * 100 = 50%
diff = |18 - (-18)| = 36
compatibilityScorePercent = 100 - (36 / 180) * 100 = 80%
```

結果: 距離感50%（繰り上げで50%）、相性80%
