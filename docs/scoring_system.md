# スコア計算システム 詳細仕様

## 概要

距離感診断では、各質問への回答（0-5の6段階）をポイント（+3〜-3点）に変換し、距離感スコアと相性スコアを算出します。

## ポイント計算

### 回答値の定義

- **0**: 最もそう思う
- **1**: そう思う
- **2**: ややそう思う
- **3**: ややそう思わない
- **4**: そう思わない
- **5**: 全くそう思わない

### ポイント変換

各質問には`closer_side`属性があり、距離感が近い方向を示します。

#### `closer_side === 'left'` の場合（そう思う側が距離感が近い）

| 回答値 | 意味 | ポイント |
|--------|------|----------|
| 0 | 最もそう思う | +3 |
| 1 | そう思う | +2 |
| 2 | ややそう思う | +1 |
| 3 | ややそう思わない | -1 |
| 4 | そう思わない | -2 |
| 5 | 全くそう思わない | -3 |

#### `closer_side === 'right'` の場合（そう思わない側が距離感が近い）

| 回答値 | 意味 | ポイント |
|--------|------|----------|
| 0 | 最もそう思う | -3 |
| 1 | そう思う | -2 |
| 2 | ややそう思う | -1 |
| 3 | ややそう思わない | +1 |
| 4 | そう思わない | +2 |
| 5 | 全くそう思わない | +3 |

### 数学的定義

```javascript
function calculatePoint(answer, closerSide) {
  if (closerSide === 'left') {
    return 3 - answer;  // 0→+3, 1→+2, 2→+1, 3→-1, 4→-2, 5→-3
  } else { // closerSide === 'right'
    return answer - 3;  // 0→-3, 1→-2, 2→-1, 3→+1, 4→+2, 5→+3
  }
}
```

## 個人スコア計算

### 各人のポイント合計

```javascript
scoreA = Σ(calculatePoint(answerA[i], question[i].closer_side))  // i = 1..30
scoreB = Σ(calculatePoint(answerB[i], question[i].closer_side))  // i = 1..30
```

- **範囲**: -90 〜 +90 点（30問 × ±3点）
- **最大値**: +90点（すべての質問で距離感が近い方向に回答）
- **最小値**: -90点（すべての質問で距離感が遠い方向に回答）

## 距離感スコア

### 計算式

```javascript
totalPoints = scoreA + scoreB  // 範囲: -180 〜 +180
distanceScorePercent = ((totalPoints + 180) / 360) * 100  // 範囲: 0 〜 100%
```

### 説明

- 二人のポイント合計を180満点として%変換
- 0%: 二人とも距離感が最も遠い（totalPoints = -180）
- 50%: 二人のポイント合計が0（バランス）
- 100%: 二人とも距離感が最も近い（totalPoints = +180）

### 10段階分類

| 範囲 | ペアタイプID |
|------|-------------|
| 0-10% | 1: 他人行儀ペア |
| 11-20% | 2: 敬語ギリ卒ペア |
| 21-30% | 3: ゆる友だちペア |
| 31-40% | 4: 放課後トークペア |
| 41-50% | 5: 安心基地ペア |
| 51-60% | 6: 同盟ペア |
| 61-70% | 7: ほぼ相棒ペア |
| 71-80% | 8: べったり予備軍ペア |
| 81-90% | 9: 密着カップル級ペア |
| 91-100% | 10: 一心同体ペア |

### 境界値の扱い

- 0%以上10%以下 → ペアタイプ1
- 11%以上20%以下 → ペアタイプ2
- ...
- 91%以上100%以下 → ペアタイプ10

## 相性スコア

### 計算式

```javascript
diff = Math.abs(scoreA - scoreB)  // 範囲: 0 〜 180
compatibilityScorePercent = 100 - (diff / 180) * 100  // 範囲: 0 〜 100%
```

### 説明

- 二人のポイント差が小さいほど相性が高い
- 0%: 二人のポイント差が最大（180点）
- 50%: 二人のポイント差が中程度（90点）
- 100%: 二人のポイントが完全に一致（差0点）

### 10段階分類

| 範囲 | 評価 |
|------|------|
| 0-10% | 相性低い |
| 11-20% | 相性やや低い |
| 21-30% | 相性低め |
| 31-40% | 相性中程度（低め） |
| 41-50% | 相性中程度 |
| 51-60% | 相性中程度（高め） |
| 61-70% | 相性高め |
| 71-80% | 相性やや高い |
| 81-90% | 相性高い |
| 91-100% | 相性非常に高い |

## 計算例

### 例1: 理想的なケース

- Aさん: 全質問で「最もそう思う」（回答0、closer_side='left'）→ +90点
- Bさん: 全質問で「最もそう思う」（回答0、closer_side='left'）→ +90点

```
totalPoints = 90 + 90 = 180
distanceScorePercent = ((180 + 180) / 360) * 100 = 100%
diff = |90 - 90| = 0
compatibilityScorePercent = 100 - (0 / 180) * 100 = 100%
```

結果: 距離感100%、相性100%

### 例2: バランスの取れたケース

- Aさん: +45点
- Bさん: +45点

```
totalPoints = 45 + 45 = 90
distanceScorePercent = ((90 + 180) / 360) * 100 = 75%
diff = |45 - 45| = 0
compatibilityScorePercent = 100 - (0 / 180) * 100 = 100%
```

結果: 距離感75%、相性100%

### 例3: 差があるケース

- Aさん: +60点
- Bさん: -30点

```
totalPoints = 60 + (-30) = 30
distanceScorePercent = ((30 + 180) / 360) * 100 = 58.33%
diff = |60 - (-30)| = 90
compatibilityScorePercent = 100 - (90 / 180) * 100 = 50%
```

結果: 距離感58.33%（繰り上げで59%）、相性50%

## 実装上の注意事項

1. **未回答の扱い**: 未回答の質問は計算から除外
2. **%表示**: 繰り上げの2桁表示（例: 52.3% → "53"、9.1% → "10"）
3. **境界値**: 10段階分類の境界値は`>=`と`<=`で判定
4. **負の値**: 個人スコアは-90〜+90の範囲なので、負の値も表示可能
5. **距離感スコア**: -180点を0%、0点を50%、+180点を100%とする線形変換
