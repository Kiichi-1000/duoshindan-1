# 距離感診断 - 要件定義

## プロジェクト概要

二人の「距離感」を診断するWebアプリケーション。質問への回答に基づいて、距離感スコアと相性スコアを算出し、10段階のペアタイプを表示する。

## 機能要件

### 1. 診断機能

#### 1.1 質問機能
- [ ] 30問の質問を表示
- [ ] 「そう思う/そう思わない」の6段階選択（0-5）
- [ ] 質問を5問ずつ6ページに分割
- [ ] トップページで最初の5問をプレビュー

#### 1.2 回答機能
- [ ] Aさん・Bさんそれぞれが回答可能
- [ ] 回答の自動保存（localStorage）
- [ ] 回答済みの質問に戻った際に回答を復元

#### 1.3 自動スクロール
- [ ] 質問回答後の次の質問への自動スクロール
- [ ] ページ遷移時のページトップへの自動スクロール

### 2. スコア計算機能

#### 2.1 ポイント計算
- [ ] 各質問の回答（0-5）を+3〜-3点に変換
- [ ] `closer_side`に基づいた適切なポイント変換
- [ ] 各人のポイント合計を計算（-90〜+90点）

#### 2.2 距離感スコア
- [ ] 二人のポイント合計を計算
- [ ] 180満点として0-100%に変換
- [ ] 10段階分類（0-10%, 11-20%, ..., 91-100%）

#### 2.3 相性スコア
- [ ] 二人のポイント差を計算
- [ ] 180満点として0-100%に変換（差が小さいほど高い）
- [ ] 10段階分類

### 3. 結果表示機能

#### 3.1 スコア表示
- [ ] 距離感スコアを%表示（XX.XX%）
- [ ] 相性スコアを%表示（XX.XX%）
- [ ] A/B個別ポイント表示（-90〜+90点）

#### 3.2 ペアタイプ表示
- [ ] 距離感スコアに基づいてペアタイプを選択
- [ ] ペアタイプ名、説明、特徴、アドバイスを表示

#### 3.3 共有機能
- [ ] 結果のURL共有
- [ ] SNS共有（Twitter、LINE等）
- [ ] 結果画像の生成

### 4. ページ構成

- [ ] トップページ（Q1-5プレビュー）
- [ ] 診断ページ（Q6-30）
- [ ] 結果ページ
- [ ] タイプ別解説ページ（Note）
- [ ] FAQページ

## 非機能要件

### 1. パフォーマンス
- モバイル最適化
- 高速表示（LCP最適化）
- 自動保存機能

### 2. ユーザビリティ
- 直感的なUI/UX
- レスポンシブデザイン
- 進捗表示

### 3. データ管理
- localStorage による自動保存
- URLパラメータによる共有

## ユーザーストーリー

### US-1: トップページで診断開始
**As a** ユーザー  
**I want to** トップページで最初の5問に回答できる  
**So that** すぐに診断を始められる

### US-2: 診断の完了
**As a** ユーザー  
**I want to** 30問すべてに回答できる  
**So that** 正確な診断結果を得られる

### US-3: 結果の確認
**As a** ユーザー  
**I want to** 距離感スコアと相性スコアを確認できる  
**So that** 二人の関係性を理解できる

### US-4: 結果の共有
**As a** ユーザー  
**I want to** 診断結果をSNSで共有できる  
**So that** 友人に結果を伝えられる
