# ドキュメントディレクトリ

このディレクトリには、距離感診断プロジェクトの開発に関するドキュメントが含まれています。

## ドキュメント一覧

### プロジェクト管理
- **[requirements.md](./requirements.md)** - プロジェクトの要件定義と機能一覧
- **[progress.md](./progress.md)** - タスク進捗管理と実装状況の追跡

### 設計・仕様
- **[architecture.md](./architecture.md)** - システムアーキテクチャとファイル構成
- **[scoring_system.md](./scoring_system.md)** - スコア計算システムの詳細仕様
- **[question_design_guidelines.md](./question_design_guidelines.md)** - 質問設計のガイドライン

### 質問・計算
- **[questions_and_calculation.md](./questions_and_calculation.md)** - 全30問の質問内容と計算方法の詳細

## 開発フロー

1. `requirements.md`で要件を確認
2. `progress.md`で進捗を管理
3. `question_design_guidelines.md`に基づいて質問を設計
4. `scoring_system.md`に従ってスコア計算を実装
5. `architecture.md`を参照してコード構造を確認
