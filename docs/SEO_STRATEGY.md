# SEO対策戦略ドキュメント

## 目標検索ワードと優先順位

1. **第1優先**: 距離感診断
2. **第2優先**: ペア診断
3. **第3優先**: 仲良さ診断

## 実施したSEO対策

### 1. メタタグ最適化

#### index.html
- タイトルタグ: 「距離感診断 | 二人の心の距離を0〜100で見える化 - 無料ペア診断」
- メタディスクリプション: 主要キーワードを含む詳細な説明
- メタキーワード: 「距離感診断,ペア診断,仲良さ診断,相性診断...」
- lang属性: `ja`（日本語）

#### 各ページのHelmetメタタグ
- **TopPage**: 距離感診断を主キーワードに
- **NotePage**: ペアタイプを主キーワードに
- **FAQPage**: 距離感診断FAQとして最適化
- **ResultPage**: noindex設定（個人情報に関わるため）
- **DiagnosisPage**: noindex設定（診断途中のため）

### 2. Open Graph / Twitter Card

全ページにOGタグとTwitter Cardを実装：
- `og:title`: ページタイトル
- `og:description`: ページ説明
- `og:image`: OG画像（要作成）
- `og:type`: website
- `og:url`: 正規URL
- `twitter:card`: summary_large_image

### 3. 構造化データ（JSON-LD）

#### TopPage
- `@type: WebApplication`: アプリケーション情報
- `keywords`: 主要キーワード
- `offers`: 無料であることを明示

#### NotePage
- `@type: Article`: 記事として構造化
- `headline`: ペアタイプ別解説
- `keywords`: ペアタイプ関連キーワード

#### FAQPage
- `@type: FAQPage`: FAQページとして構造化
- 各質問・回答を`Question`/`Answer`として構造化

### 4. サイトマップ・robots.txt

#### sitemap.xml
- `/` (優先度1.0)
- `/note` (優先度0.9)
- `/faq` (優先度0.8)

#### robots.txt
- 全ページをクロール許可
- sitemap.xmlの場所を指定

### 5. コンテンツ最適化

#### キーワード配置
- **H1タグ**: 「距離感診断」（TopPage）
- **H2タグ**: 「距離感診断・ペア診断の流れ」（TopPage）
- **本文**: 自然な形でキーワードを配置
- **アンカーテキスト**: 「距離感診断」「ペア診断」「仲良さ診断」を含む

#### 内部リンク構造
- Headerナビゲーション
- Footerリンク
- ページ間の自然なリンク

### 6. パフォーマンス最適化

- モバイルフレンドリー（viewport設定）
- レスポンシブデザイン
- 画像の遅延読み込み（必要に応じて）
- CSS最適化（Tailwind JIT）

## 追加で必要な作業

### 1. OG画像の作成
- `/public/og-image.jpg` (1200x630px推奨)
- 距離感診断のブランディングに合わせた画像

### 2. ドメイン設定
- `index.html`、`sitemap.xml`、`robots.txt`の`yourdomain.com`を実際のドメインに置換

### 3. Google Search Console登録
- Google Search Consoleにサイトを登録
- sitemap.xmlを送信
- インデックス登録を促進

### 4. 被リンク獲得
- SNSでのシェア促進
- 関連サイトからの被リンク
- プレスリリース（必要に応じて）

### 5. コンテンツマーケティング
- ブログ記事の追加（距離感診断について、ペア診断について等）
- 定期的なコンテンツ更新

## 検索順位向上のための施策

### 短期施策（1-3ヶ月）
1. Google Search Console登録
2. サイトマップ送信
3. インデックス登録促進
4. OG画像の最適化

### 中期施策（3-6ヶ月）
1. コンテンツの充実（NotePageの詳細化）
2. 内部リンク構造の最適化
3. ページ速度の改善
4. モバイルユーザビリティの向上

### 長期施策（6ヶ月以上）
1. 被リンク獲得キャンペーン
2. SNSマーケティング
3. ユーザー生成コンテンツ（レビュー、体験談）
4. コンテンツ更新の継続

## モニタリング指標

### 検索順位
- 「距離感診断」での順位
- 「ペア診断」での順位
- 「仲良さ診断」での順位

### アクセス解析
- オーガニック検索からのアクセス数
- 検索クエリ別のアクセス数
- ページビュー
- 直帰率
- 滞在時間

### Google Search Console
- クリック数
- インプレッション数
- CTR（クリック率）
- 平均順位

## 注意事項

1. **キーワード詰め込みの回避**: 自然な文章でキーワードを配置
2. **ユーザー体験の優先**: SEO対策よりもユーザー体験を優先
3. **定期的な更新**: コンテンツの定期的な更新で評価を維持
4. **モバイル最適化**: モバイルファーストでSEO評価が向上
